Proyectivo

A partir de las relaciones vigentes entre dimensiones, explorá qué transformaciones posibles emergen si se interviene sobre las relaciones que hoy organizan el sistema. Esto no es un plan de acción: explora posibilidades, no las prescribe.

Campo de decisiones

A partir del proyectivo vigente, este espacio ayuda a convertir parte de esas posibilidades en decisiones explícitas -- qué se elige, bajo qué criterio, y qué se descarta o posterga. Esto no ejecuta nada: registra elecciones, no tareas.

Criterios para decidir

Elegí los que importen para este negocio y, si querés, ponderalos. Podés dejar alguno sin ponderar.

Campo de decisiones propuesto

Ejecución y seguimiento

A partir de las decisiones adoptadas o condicionadas, este espacio convierte esas decisiones en acciones observables y registra su evolución real -- esperado vs. ocurrido. La IA ayuda a preparar y a leer; el usuario confirma cada acción, cada estado y cada cierre.
